# Exercícios Beecrowd — Java

Repositório criado para registrar minha prática de **lógica de programação e desenvolvimento em Java** por meio dos exercícios da plataforma Beecrowd.

Durante os exercícios, estou praticando conceitos fundamentais da linguagem, como:

* Entrada e saída de dados
* Variáveis e tipos de dados
* Operadores aritméticos e lógicos
* `if`, `else if` e `else`
* Estruturas de repetição
* Operador `%` (resto da divisão)
* Cálculos e médias
* Manipulação de números inteiros e decimais
* Vetores e estruturas de dados
* Organização e resolução de problemas

O objetivo deste repositório é acompanhar minha evolução na programação, fortalecer minha lógica e desenvolver maior autonomia na resolução de problemas utilizando Java.

**Tecnologia:** Java
**Plataforma:** Beecrowd
